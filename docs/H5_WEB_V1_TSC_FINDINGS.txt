H5_WEB_V1 tsc --noEmit Findings
=================================
环境：当前 workbuddy workspace（Karina-ZZ/smart-task-board H5 V1 同步后）
命令：npx tsc --noEmit（web/）
基线对比：HEAD = bd7400b（H5 V1 同步前）tsc 报 0 条错误

结果
----
总计 42 条 src/** 错误，分布于 10 个文件（仅 web/，后端 .py 已 py_compile 通过）。

错误类型分布
  TS2339 Property 'X' does not exist on type ...     28
  TS2559 Type has no properties in common with ...    5
  TS7006 Parameter implicitly has 'any' type          3
  TS2345 Argument of type ... not assignable          3
  TS2769 No overload matches this call                2
  TS2554 Expected N arguments, got M                 1

主要类别
--------

A. useQuery + listUsers(keyword?) 类型不兼容（基线 listUsers = listPrototypeUsers 无参数）
   - src/pages/NewTaskPage.tsx (130, 140, 355, 372, 386)
   - src/pages/TaskDetailPage.tsx (92)

B. 新增页面使用未声明的 feedback.show(...) 方法（实际接口只有 showToast）
   - src/features/notifications/NotificationsPage.tsx (67, 77)
   - src/features/task-detail/TaskCompletionPage.tsx (52, 61, 66, 70)
   - src/features/task-detail/TaskExecutionControls.tsx (126, 150, 155, 163, 168, 177, 184, 190, 196, 203, 208, 248, 250, 427, 430)
   - src/features/task-detail/TaskReportPage.tsx (65, 74)
   - src/features/task-detail/TaskReviewPage.tsx (62, 72)

C. useNavigate() 第 2 参数 state 不被 NavigateOptions 接受
   - src/features/notifications/NotificationsPage.tsx (88, 90, 92, 94, 96)

D. 新增 TaskCreateDetailsPanel / __tests__/api.test.ts 中的隐式 any / 参数数量问题
   - src/features/task-intake/TaskCreateDetailsPanel.tsx (198, 212)
   - src/features/workbench/__tests__/api.test.ts (119)

影响判定
--------
- B 类与 C 类为运行时不报错（TypeScript 仅在调用方推断过严，运行时无影响）。
- A 类可能影响 NewTaskPage / pages/TaskDetailPage 在 H5 V1 路径下的实际渲染（users.data 在严格类型下为 {}）。

与执行报告的口径关系
--------------------
执行报告 H5_WEB_V1_EXECUTION_REPORT.md §4 自报：
  "React/TypeScript 源码语法转译：103 files / 0 syntax errors"
指的是语法层（swc/esbuild parse）零错误，并非 tsc --noEmit 类型检查零错误。
报告 §6 明确承认："当前环境 npm ci 访问 registry 超时，故不能宣称 ESLint/Vitest/Vite build/Playwright PASS"。
当前 workbuddy 环境的 web/node_modules 为既有可用副本，可执行 tsc --noEmit，故发现上述 42 条类型层错误。

后续建议
--------
1. 修 listUsers 签名兼容 useQuery，或在 NewTaskPage / pages/TaskDetailPage 调用点改写 queryFn 适配 QueryFunctionContext。
2. 在 web/shared feedback 工具上补充 show() 方法或修正调用点改用 showToast()。
3. useNavigate() 第 2 参数 state 移除，或在 router 侧扩展 NavigateOptions。
4. TaskCreateDetailsPanel / api.test.ts 显式标注类型。

本附件作为本次 H5 V1 同步的真实门禁快照，不在本次 commit 中修复；保留供后续轮次处置。
