## 5. 最近 Test16 主要是在修 Bug，而不是加新功能

最近几轮实际上是在做最后的真实使用问题收口。

先修了 **Web 登录页仍显示开发占位页面**的问题，真实 `LoginPage` 已经接入 `/login`，并增加登录后的安全返回逻辑。

随后又修了：

* `task_source / 任务来源` 从必填改成选填；
* AI 还有追问时，只要真正 9 项必填字段已经完整，也可以继续发送；
* 用户先手工填写字段后再回答 AI 问题，AI 不能把用户填写好的内容覆盖；
* "接受任务"点击无反应问题；
* "验收通过"同类弹窗问题；
* 创建任务时已经确认绩效指标，但进入任务详情却显示"未关联绩效"的问题。

**最新一次就是绩效关联显示 Hotfix。**

它的根因已经定位：

```text
创建阶段 mock 数据：
  task.performanceMetricId
  task.performanceMetric

任务详情正式读取：
  performanceMatches[]
```

原来两套数据没有正确转换，所以任务实际上已经选了 KPI，但页面显示没有关联。

最新 Test16 已经增加统一 DTO 投影，任务：

```text
选择绩效指标
→ 保存草稿
→ 确认发送
→ 再次打开任务详情
```

现在仍然能够看到原来的绩效指标。

而且这个修复：

```text
数据库新增表：0
数据库新增字段：0
Alembic migration：0
后端生产代码 app/ 修改：0
```

也就是说，这次没有为了修页面显示去动任务状态机或数据库。
