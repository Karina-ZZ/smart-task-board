# 功能 02 验收单：任务/节点概览

## 已完成

- 当前用户参与任务的五类状态概览，点击状态卡直接筛选。
- 主任务与“我的节点任务”两种服务端查询模式。
- 状态快捷筛选与筛选抽屉保持一致。
- 完整筛选：任务/节点、完整状态、四象限、未来 3 天临期、需要支持、开始日期、搜索、排序与顺序。
- 自定义日期完整性及起止顺序校验，校验失败不会发起请求。
- 筛选摘要、全部条件空态、错误重试、加载骨架。
- 服务端分页与上一页/下一页；小程序不一次拉取全部任务。
- 节点卡展示父任务、节点状态、负责人、截止时间和进度；点击进入父任务并携带 `nodeId`。
- 筛选条件和滚动位置作为本地 UI 状态恢复，不写业务数据。
- 从工作台点击“全部任务”会清空临时筛选。

## 微信开发者工具体验

1. 点击底部“任务”进入任务概览。
2. 点击顶部状态数量卡，确认任务列表同步筛选并滚动到结果区。
3. 切换“主任务 / 我的节点任务”，点击节点卡检查详情跳转。
4. 打开“更多筛选”，组合选择四象限、临期、日期和排序后应用。
5. 返回详情前的任务概览，确认筛选和滚动位置恢复。
6. 在工作台点击“全部任务”，确认此前临时筛选被清空。
